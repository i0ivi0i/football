# 足球概率分析与智慧复盘

研究市场赔率、球队表现和预测质量，重点关注平局，同时完整比较胜平负。现有程序负责采集、轨迹观测与对账；没有自动学习或获利保证。

- [AGENTS分析规程](AGENTS.md)：证据边界、技能分工、八层分析与七类条件复核。
- [复盘契约](分析复盘记录/README.md)：赛前记录、赛后统计与习惯塑形流程。
- [经验与习惯塑形](分析复盘记录/总复盘总结.md)、[计数看板](分析复盘记录/总准确率.md)、[本次审计](分析复盘记录/README.md#rule-audit)。
- [论文库](温故而知新学习资料/README.md#classic-papers)、[智慧复盘论文](温故而知新学习资料/README.md#review-papers)。

## 程序分层与数据口径

- `脚本/领域`：赔率、快照、客观位移与信息充分性检查；不依赖HTTP或数据库。
- `脚本/应用`：探测及轨迹用例；`脚本/适配器`：体彩、微观数据和SQLite；`脚本/心电图录像机.py`：CLI组装入口。
- had是普通胜平负，hhad是让球胜平负；快照及账本保留市场类型、让球线。旧账本首次打开时追加列，并由既有让球标记回填，不改原赔率。
- 按场次查轨迹默认取最新比赛ID及同市场；过去其他比赛原记录仍保留。不同市场、让球线或比赛不计算连续位移。
- `去水公平概率()`为兼容名称，实际是倒数比例归一化市场概率，并非Shin或已知真实概率。
- 两个旧`校验…平局资格()`接口保留名称，返回`(None, 原因)`表示待评估；调用者须显式处理None，不得当成否决、推荐或已校准概率。
- 微观数据缺失返回None或错误说明；完场状态与常规时间可结算分开。AET/PEN不能用加时或点球比分结算常规胜平负。
- 访问API按覆盖与需要使用；配额、认证及数据时效以当次响应为准，不在报告中放凭证。

## 最小工作流程

赛前先核对时钟与开球时间，读取规程和相关经验，query相关图谱；采集必要数据并保存概率、来源和实际记录时间。临场更新保留旧版本。
赛后先审赛前判断，再揭示赛果；记录成功、失败、反例与未选样本。数据错误及时修复，统计模式先保留假设，允许本次不改规则。
经验的作用是塑造下次检查与判断习惯；具体写法见[总复盘总结](分析复盘记录/总复盘总结.md)。
历史预测和复盘保持原样用于审计；其中“内幕”“必赚”“硬红线”等旧断言不能直接作为现行规程或已验证因果。

## 本地命令（PowerShell）

```powershell
$env:PYTHONPATH='脚本'
$env:PYTHONDONTWRITEBYTECODE='1'
python 脚本/心电图录像机.py --单次探测
python 脚本/心电图录像机.py --轨迹回溯 '周一002'
python 脚本/对账机.py
python -m pytest 脚本/测试 -q -p no:cacheprovider
graphify query '条件复盘 习惯塑形'
graphify update .
```

采集命令会调用网络并写账本；对账命令仅重建看板。没有验证过的后台自动触发不称为自动生效。
图谱更新用官方工具；文档变更另做语义更新，检查真实来源与悬空链接，允许有理由的孤立节点。旧`深度联想连线.py`只做只读审计，停止批量臆造关系。
