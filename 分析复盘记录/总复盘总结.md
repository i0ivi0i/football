# 智慧经验与习惯塑形

执行[分析规程](../AGENTS.md)及[复盘契约](README.md)，方法依据见[论文索引](../温故而知新学习资料/README.md#review-papers)。本页是待持续检验的行动经验，不代表阈值已验证或自动提高胜率。

## 核心习惯：先看证据，再形成倾向

| 触发情境 | 下次具体动作 | 为什么值得做 | 反馈与失效条件 |
| --- | --- | --- | --- |
| 单场推荐失手或未选比赛打平 | 先隐藏结果重读赛前依据，再检查概率与价格 | 减少结果偏见，避免把低概率发生当必然判断错误 | 发现数据错误立即修；没有成组证据先不改规则 |
| 平项赔率下降或不同机构报价分歧 | 对齐时间、市场、抽水与三项隐含概率，列替代解释 | 赔率变动是观测，不能单独识别机构意图 | 数据不同步则先补齐；来源一致也不等于因果确认 |
| 球队伤停或休赛短 | 核查缺阵位置、替代者、出场分钟以及双方攻防 | 进攻减弱与防守减弱可能并存，不能只推闷平 | 样本不足注明；不按休赛3天或对抗60%直接翻方向 |
| 强弱悬殊或平赔高 | 比较完整概率与价格，检查弱方防守失球、强队多赛疲劳与阻盘区间，严禁机械一刀切杀平 | 高赔率可能对应冷平机会；强队胜赔低于1.60不是必胜保证 | 弱队防守彻底漏洞且强队全主力时排除；不盲目逆势重注 |
| 非欧或早场赛事(彻底废黜五大联赛特权) | 严禁以联赛知名度定优先级；推演唯一依据为【关盘风控 > 概率模型 > 攻防数据】，亚冠/日韩/北欧等小联赛与五大联赛享受 100% 对等第一顺位待遇 | 早场非欧战术纪律严明且假球少，低水平项具备高价值 | 仅因联赛冷僻作为降级、漏选或后置理由，直接判定为重大违纪 |
| 双方开放对攻 | 同时评估胜负与所有平局比分，检查尾部 | 低比分平局减少不意味着所有平局消失 | 未算联合分布不直接指定2:2/3:3，更不自动推荐 |
| 只有让球市场 | 先确认让球数及结算口径，保留普通胜平负未知 | 让球平和常规平局不是同一事件 | 不把停售当内幕；没有完整价格无法认证对冲效果 |
| 体彩故意关闭基础胜平负(had缺失)仅开让球盘 | 100% 穷尽排查所有关盘场次，严禁因非欧/杯赛/次级联赛主观忽略，核验受让方铁桶防守与豪门跨国/慢热疲劳(如09-14吉达国民1:1棉农) | 机构关盘表明常规胜平负存在高风控隐患，终局小胜或平局通杀具备极端价值 | 受让方防守漏风(失球>1.5)且豪门主力齐整火力碾压时除外 |
| 高转换联赛(英超/德甲)对攻战且场均失球>1.4 | 严禁推 2:2 平局，重点防单边防线崩盘惨案(3:1/4:1)，分胜负概率远大于对攻互锁 | 攻强守弱遭遇高速对抗易打穿，前日比分不能直接套用 | 双方主力中卫均健康且战术保守时除外 |
| 胜赔<1.50强弱悬殊博冷平 | 严格核验强队72h双赛/跨国远征、弱队近5场失球≤1.0及中轴无伤停，缺一严禁博冷 | 避免反向极端与无证据盲目博冷(如09-14都灵) | 弱队防线有任何硬实力硬伤时直接排除 |
| 盲目追逐低平赔(赌徒谬误) | 严禁以平赔高低定优劣；平赔2.85仍有近70%分胜负且EV往往为负；推演必须联立【总进球期望λ<2.0 + 正期望值EV(>0) + 阻盘特征】，高平阻盘(3.50~4.20)与均势低平对等评估 | 仅看赔率越低越买，必然落入抽水负收益陷阱；高赔率被庄家刻意抬高往往隐藏巨大正期望值 | 未做独立进球期望与EV测算时不能断言价值 |
| 大球对攻与防线崩盘场景 | 严禁凭天气、赛程等单一外部变量单向推导平局；必须联立双方攻防效率与预期进球期望λ，当防守不稳且对攻活跃时，必须充分评估打穿分胜负概率 | 防线失衡的大球对攻环境会大幅压缩平局概率空间 | 双方防守组织严密(失球均<1.0)且锋线转化率低下时除外 |
| 势均力敌赛事的基准率审查 | 即使两队Elo实力极度接近，分胜负基准概率通常仍占 65%~75%；不能将均势简单等同于必然打平，高平赔应结合多源市场真实去水概率评估，避免主观确认偏误 | 足球单球即可打破僵局，均势平局依然是小概率事件，需严格核查赔率性价比 | 淘汰赛双回合战术平衡或积分互保明确时除外 |
| Polymarket 交易场景物理对齐 | 结合主人实际交易场景，推演必须前置确认 Polymarket 是否上线对应赛事的 Draw 市场及其实时美分价格；未开盘场次明确标注不可交易，不列入实操主推 | 确保推演结论与实际操作无缝衔接，避免推演无法执行的标的 | 后续平台补开对应市场时动态纳入 |
| 发现一条看似有效的新经验 | 写下反例、适用范围和撤回条件，冻结后用后续比赛比较 | 控制偶然关联与事后调参，允许旧经验失效 | 不稳定就保持假设、缩小范围或撤回，不堆例外补丁 |

## 塑形闭环

**触发情境 → 执行检查 → 记录判断 → 对照反馈 → 修正习惯。**
检查是否真的执行、是否减少信息遗漏与概率误差；不以写了多少规则、连了多少图谱边衡量学习。
优先养成三个动作：结论前找一个反例；改规则前找独立样本；复用经验前检查情境是否仍成立。
当数据充足且判断流程已稳定，可减少重复操作；当阵容、联赛、盘口或数据来源变化，重新检验适用性。

## 经验记录的最小格式

- 适用情境与触发信号：说明对什么问题有用，保留连续数值及样本信息。
- 检查动作与理由：下一次具体查什么、怎样可能改善决策；机制尚未证实时标为假设。
- 支持证据与反例：引用赛前封存及后续样本，成功失败都保留；缺少证据就写未知。
- 暂定调整、比较办法与后续反馈：允许不调整，区分拟议、试验中、已验证和已撤回。
- 失效条件：在哪些联赛、时间、市场或数据条件下不能照搬。

## 历史经验如何保留

旧七类盘口原型中的有用问题已转成上述检查习惯；“庄家必赚”“关闭had必然内幕”、固定得分和赛果否决不再作为公理。
旧战报原文仍在[档案目录](README.md)，用于检查当时推理；其中单场机构动机叙述、旧阈值与胜率宣称属于待核查材料。
[规则审计](README.md#rule-audit)保留变更依据与边界，避免遗忘错误来源，也避免把错误永久当成事实。

## 八篇复盘学术论文的闭环行动法则（彻底杜绝死板一刀切）

复盘不是为单场输赢找借口，更不是为每一次失手加一条死板禁令。本知识库八篇核心论文构成了不可动摇的科学复盘闭环：

1. **[Aiyer 等 (2023) 结果偏见与决策评价](../温故而知新学习资料/2023_Aiyer_结果偏见与决策评价.md)**：**过程与结果解耦**。赛后必须先遮住比分审核赛前推演逻辑与期望值，严禁因单场未平就否定科学策略，绝不允许单场成败推翻规则。
2. **[Hewamalage 等 (2023) 预测评估陷阱与最佳实践](../温故而知新学习资料/2023_Hewamalage_预测评估陷阱与最佳实践.md)**：**防事后偷看与过度切分**。严禁将每天轮换的临时场次代号当成经验分类，严禁事后对数据过度切分寻找虚假规律。
3. **[Wheatcroft (2019) 足球概率预测评分](../温故而知新学习资料/2019_Wheatcroft_足球概率预测评分.md)**：**完整概率质量评估**。使用 Brier Score 与 Ignorance Score 评估三项概率分布质量，绝不做简单粗暴的二元对错复盘。
4. **[Wilkens (2026) 德甲预测与滚动验证](../温故而知新学习资料/2026_Wilkens_德甲预测与滚动验证.md)**：**极简主义（KISS）与样本外检验**。简单模型往往优于过度复杂的规则堆砌；规则优化必须在滚动未知样本中检验，严禁叠床架屋堆砌例外。
5. **[Dimitriadis 等 (2021) 稳定可靠性图 (CORP)](../温故而知新学习资料/2021_Dimitriadis_稳定可靠性图_CORP.md)**：**大样本概率校准**。30% 的平局概率意味着 70% 的分胜负是正常物理分布；只有累积大样本偏离校准曲线才触发参数更新。
6. **[Giacomini & White (2006) 条件预测能力检验 (CPA)](../温故而知新学习资料/2006_Giacomini_条件预测能力检验.md)**：**假设预先冻结**。任何策略修正必须在事先冻结假设与检验窗口后进行统计检验，禁止赛后随兴解释。
7. **[Choe & Ramdas (2023) 序贯预测者比较](../温故而知新学习资料/2023_Choe_序贯预测者比较_arXiv_v6.md)**：**置信序列长期跟踪**。以时间序列动态跟踪模型累计表现，克服单日情绪波动，杜绝反复查看结果后的选择性偏差。
8. **[Macrì 等 (2025) 足球贝叶斯加权动态模型](../温故而知新学习资料/2025_Macri_足球贝叶斯加权动态模型_arXiv.md)**：**平滑衰减自适应**。球队攻防能力呈动态漂移，采用时间衰减平滑更新参数，绝不因单场突发赛果剧烈重置系统认知。
