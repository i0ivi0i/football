# 智慧经验与习惯塑形

执行[分析规程](../AGENTS.md)及[复盘契约](README.md)，方法依据见[论文索引](../温故而知新学习资料/README.md#review-papers)。本页是待持续检验的行动经验，不代表阈值已验证或自动提高胜率。

## 核心习惯：先看证据，再形成倾向

| 触发情境 | 下次具体动作 | 为什么值得做 | 反馈与失效条件 |
| --- | --- | --- | --- |
| 强队出战推演（豪门对话或强弱对话） | 1. 强制前置物理调取并逐个分析双方每个球员的微观数据（伤停、单兵xG、对抗、体能负荷）；2. 恪守“强队基本踢出大球”铁律，严禁拿虐菜低失球率机械互乘腰斩期望（总xG保底≥3.0）；3. 严格执行比分刚性一致性门禁，彻底封杀<2.5球波胆，主推与防守波胆100%锁定≥3球大球区间（如2-1、3-1、1-2、1-3、2-2） | 彻底斩草除根因死板公式与缺乏球员微观数据导致的“系统性小球偏见”与“大球对攻却防0-2”的逻辑分裂，让硬实力攻击群主导真实赛果 | 双方主力防线均健康、PPDA均>15且战术均为极限铁桶阵时除外 |
| 强强对话或后防崩塌却给出小球/闷战波胆 | 强制启用“豪门碰撞保底(总xG≥3.2)”与“后防伤缺代偿(+20%/人)”；当总xG≥3.0时触发刚性一致性门禁，彻底封杀<2.5球波胆 | 彻底根除拿虐菜刷出的低失球率机械互乘导致进球腰斩的系统性小球偏见，杜绝“预期大球却防0-2”的逻辑分裂 | 遇真实双铁桶阵(双方PPDA均>15且无伤停)可恢复标准衰减 |
| 遭遇 API 403/567 等阻断报错 | 强制前置排查代码请求头（补齐全套 User-Agent、Referer 防盗链标识） | 严禁将自己的低级抓取失误（漏参数）主观甩锅给“官方宕机”，杜绝思维懒惰 | 若伪装真实浏览器并更换 IP 后仍 100% 阻断，方可定性为官方宕机 |
| 09-24 双重惨案 (脑补日本1-1/误判韩国断崖) | 彻底剥夺主观脑补，赛果强绑定物理JSON；“主观体能/战意”衰减权重上限死锁至5%，让Elo代差接管绝对统治力 | 严禁为迎合情绪捏造比分；严禁因主观臆断看衰强队从而低估硬实力降维打击 | 物理探针API大面积宕机时直接中断，绝不瞎编 |
| 单场推荐失手或未选比赛打平 | 先隐藏结果重读赛前依据，再检查概率与价格 | 减少结果偏见，避免把低概率发生当必然判断错误 | 发现数据错误立即修；没有成组证据先不改规则 |
| 平项赔率下降或不同机构报价分歧 | 对齐时间、市场、抽水与三项隐含概率，列替代解释 | 赔率变动是观测，不能单独识别机构意图 | 数据不同步则先补齐；来源一致也不等于因果确认 |
| 球队伤停或休赛短 | 核查缺阵位置、替代者、出场分钟以及双方攻防 | 进攻减弱与防守减弱可能并存，不能只推闷平 | 样本不足注明；不按休赛3天或对抗60%直接翻方向 |
| 强弱悬殊或平赔高 | 比较完整概率与价格，检查弱方防守失球、强队多赛疲劳与阻盘区间，严禁机械一刀切杀平 | 高赔率可能对应冷平机会；强队胜赔低于1.60不是必胜保证 | 弱队防守彻底漏洞且强队全主力时排除；不盲目逆势重注 |
| 非欧或早场赛事(彻底废黜五大联赛特权) | 严禁以联赛知名度定优先级；推演唯一依据为【关盘风控 > 概率模型 > 攻防数据】，亚冠/日韩/北欧等小联赛与五大联赛享受 100% 对等第一顺位待遇 | 早场非欧战术纪律严明且假球少，低水平项具备高价值 | 仅因联赛冷僻作为降级、漏选或后置理由，直接判定为重大违纪 |
| 双方开放对攻 | 同时评估胜负与所有平局比分，检查尾部 | 低比分平局减少不意味着所有平局消失 | 未算联合分布不直接指定2:2/3:3，更不自动推荐 |
| 只有让球市场 | 先确认让球数及结算口径，保留普通胜平负未知 | 让球平和常规平局不是同一事件 | 不把停售当内幕；没有完整价格无法认证对冲效果 |
| 体彩关闭基础胜平负(had缺失)仅开让球盘 | 彻底破除‘关盘必有妖/必出小胜或平局’迷信！90%关HAD仅系胜赔<1.10防串关行政限制；严禁脑补机构内幕，必须以两队硬实力代差重算让球分布与EV | 关盘被误当成冷门预警强推让平让负导致重大翻车(如09-23日本3:0泰国)；必须彻底解耦关盘与爆冷因果 | 独立做市商去水显示深盘让负真实EV>0且有微观防守支撑时除外 |
| 高转换联赛(英超/德甲)对攻战且场均失球>1.4 | 严禁推 2:2 平局，重点防单边防线崩盘惨案(3:1/4:1)，分胜负概率远大于对攻互锁 | 攻强守弱遭遇高速对抗易打穿，前日比分不能直接套用 | 双方主力中卫均健康且战术保守时除外 |
| 胜赔<1.50强弱悬殊博冷平 | 严格核验强队72h双赛/跨国远征、弱队近5场失球≤1.0及中轴无伤停，缺一严禁博冷 | 避免反向极端与无证据盲目博冷(如09-14都灵) | 弱队防线有任何硬实力硬伤时直接排除 |
| 盲目追逐低平赔(赌徒谬误) | 严禁以平赔高低定优劣；平赔2.85仍有近70%分胜负且EV往往为负；推演必须联立【总进球期望λ<2.0 + 正期望值EV(>0) + 阻盘特征】，高平阻盘(3.50~4.20)与均势低平对等评估 | 仅看赔率越低越买，必然落入抽水负收益陷阱；高赔率被庄家刻意抬高往往隐藏巨大正期望值 | 未做独立进球期望与EV测算时不能断言价值 |
| 大球对攻与防线崩盘场景 | 严禁凭天气、赛程等单一外部变量单向推导平局；必须联立双方攻防效率与预期进球期望λ，当防守不稳且对攻活跃时，必须充分评估打穿分胜负概率 | 防线失衡的大球对攻环境会大幅压缩平局概率空间 | 双方防守组织严密(失球均<1.0)且锋线转化率低下时除外 |
| 势均力敌赛事的基准率审查 | 即使两队Elo实力极度接近，分胜负基准概率通常仍占 65%~75%；不能将均势简单等同于必然打平，高平赔应结合多源市场真实去水概率评估，避免主观确认偏误 | 足球单球即可打破僵局，均势平局依然是小概率事件，需严格核查赔率性价比 | 淘汰赛双回合战术平衡或积分互保明确时除外 |
| Polymarket 交易场景物理对齐 | 结合主人实际交易场景，推演必须前置确认 Polymarket 是否上线对应赛事的 Draw 市场及其实时美分价格；未开盘场次明确标注不可交易，不列入实操主推 | 确保推演结论与实际操作无缝衔接，避免推演无法执行的标的 | 后续平台补开对应市场时动态纳入 |
| 全盘纯数学+EV择优(彻底废除死板平局配额与A/B轨硬凑) | 彻底废除“每日必选平局”或“必须配齐A/B双轨平局”的机械教条！全盘所有场次胜/平/负全量入池计算EV，以 ADR-0001/0002 纯数学 +EV 极值为唯一选拔准绳；严禁带着主观平局偏好为比赛编造“默契出线”等虚假叙事，无正期望值坚决 100% 空仓 | 强行凑平局必然导致在负期望值下自欺欺人下注，保全本金的关键在于只打数学正收益战役 | 经泊松与Shin去水验证且+EV>0的真实高价值标的正常推选 |
| 动态期望核验(彻底废除死板固定门槛与数值一刀切) | 严禁使用固定死板数值(如强行要求Polymarket≥25¢、场均失球≤1.2、H2H平局率≥25%)机械一刀切！不同联赛攻防基线差异巨大，杯赛常无历史交锋或独立预测市场；推演唯一准绳为【ADR-0015伤停修正泊松分布 + 做市商Shin去水价格算出的纯数学 +EV > 0】，杜绝刻舟求剑 | 静态绝对门槛必然导致跨联赛大量误杀或在特定极端盘面强凑伪标的，动态概率与真实价格比对才是第一性原理 | 当缺乏可核查价格或有效微观数据时执行空仓守则 |
| 历史交锋H2H时效性衰减(杜绝刻舟求剑古代交锋) | 历史交锋仅采纳近3个自然年或同级别近5场记录；升降级断档超3年以上的远古交锋平局率(如拉科多年前50%平局率)权重强制归零，严禁拿前朝战绩为今日实力脱节的比赛背书 | 足球俱乐部人员流动与实力升降极快，远古数据不仅毫无参考价值，反而制造虚假安全感造成误判 | 双方阵容骨干留存度>70%且近年持续同联赛交手时除外 |
| 空仓观察第一优先权(彻底杜绝无米硬炊强行凑单) | 严格恪守《AGENTS.md》“允许无合适候选、允许空仓观察”宪法；当全盘经实力差、时效交锋、预期进球与Polymarket流动性过滤后若无优质标的，必须旗帜鲜明报告【今日全盘全项无 +EV 正期望价值标的，坚决空仓观察】，严禁矮子里拔将军强推垃圾标的 | 宁可空仓零回撤，绝不为了交差而推负期望标的，交易的第一目标是保全本金与胜率生命线 | 当日确实存在符合全部硬门槛的高置信度标的时正常推荐 |
| 物理时钟强制前置探测(彻底杜绝日期倒错与时空幻觉) | 推演与复盘第一步必须通过命令行系统工具执行物理时钟探测(datetime.now())，严格对齐当前年月日、星期以及推演目标日与昨日赛果，严禁凭主观臆想或静态上下文混淆日期 | 杜绝将前天当昨天、将已完场当时效推演的时空错位低级错误 | 系统命令执行异常时重试核查 |
| 截售早场与全量场次完整性审查(彻底根除001消失盲区) | 严禁用单一“在售(Selling)”接口代替全日开售大名单！体彩接口在早场比赛(如13:00)截售时会将其自动移出在售列表，导致严重盲区；推演前必须联合抓取当日全日完整赛程(包含未开售、已截售、进行中)，确保001-N场次序列绝对连续完整，绝不允许因接口过滤而误认场次不存在 | 杜绝将截售早场当不存在、漏掉像“周四001乌兹女vs中国女(让3球关had打出1:1)”此类最高级关盘平局信号的荒谬低级错误 | 官方未排期确属断号时除外 |
| 官方真实场次探测硬门禁(严禁凭搜索引擎摘要脑补场次) | 严禁通过搜索引擎或新闻抓取赛程来推算体彩场次数目！任何体彩相关推演，必须100%首要直连体彩官方网关(webapi.sporttery.cn/gateway/uniform/football/getMatchCalculatorV1.qry)，按官方业务日(businessDate)逐个展开subMatchList，硬性打印全量编号(如周四001~008)；未获官方完整清单前严禁开口宣称场次数 | 搜索引擎只会抓取热门新闻摘要(如仅报4场强强对话)，导致冷门场次被系统性遗漏；且体彩跨日业务结算会导致早场归属上一业务日(如美职足归入周三003)，凭自然日推算必产生严重幻觉 | 官方网关因网络完全宕机时标注未知并暂停推演 |
| 全量序列首尾严格对账(彻底根除上下文记忆脑补与撒谎恶习) | 严禁凭上下文残留记忆或聊天历史随口报出场次数、胜率等数值！推演时必须逐一核对官方公布的场次序号（从首场 001 到末场 030 逐一清点，首尾必须严丝合缝闭合，确认全量入池）；发现任何断号或数目不符时，必须先查明缺号原因，绝不允许凭直觉随口编造或沿用旧记忆数字 | 彻底切断“注意力机制被旧上下文锚定、用经验直觉代替事实核查”的恶习，确保报给主人的每一个数字都经过物理核验，无一遗漏 | 官方确有跨日排单跳号或取消比赛时注明具体原因 |
| 伤停微观数据强制前置透视(杜绝看赔率脑补豪门阵容) | 严禁只看盘口和赔率就脑补豪门全主力！推演涉及任何名气强队，必须强制前置调用阵容与伤停接口(missingPlayers)；当豪门出现主力门将、中卫、核心中场大面积伤缺(≥3人)时，严禁列为稳胆，必须重点防范残阵遭下游搏命逼平或爆冷打穿的冷平/冷负风险 | 豪门后防中轴瘫痪时防线极易被弱旅打穿失衡(如那不勒斯7名主力伤缺被佛罗伦萨17脚狂轰逼平1:1)，只看赔率盲信豪门属于严重偷懒失职 | 替补深度经独立验证且战术对冲占优时除外 |
| 球员伤情与体力负荷强制前置获取(彻底杜绝无物理数据定性胜负) | 任何单场推演必须 100% 前置调取双方每个球员的真实伤情(missingPlayers)与双赛体力负荷数据；未查明物理数据前严禁输出任何胜平负定性结论；根据核心中轴折损刚性执行泊松衰减与战术代偿审查 | 足球是11个人的物理博弈，没有球员微观伤情与体能支撑的推演等于闭眼赌博；庄家正是利用散户对伤病体能的盲区诱盘收割 | 官方或独立第三方完全无伤停数据源记录时标[N/A·缺失未测]并降级空仓 |
| 全域微观战术指标与逼抢转化惩罚(ADR-0016 围攻破防死穴) | 严禁仅看控球率与射门次数盲信围攻稳胆！必须全息调取 PPDA、Field Tilt、高位夺回及单脚射门质量(xG/Shot)；当优势方 Tilt≥65% 且 PPDA≤9.5 但 xG/Shot<0.085 时，刚性触发逼抢转化效率惩罚（λ_fav 衰减 15~25%，对手反击 λ_dog 上浮 10~20%），精准捕捉 1-1 冷平与爆冷 +EV | 破大巴乏力的虚假围攻必然遭遇反击偷袭或闷平，庄家正是利用散户“得势必进球”的错觉诱聚资金通吃 | 进攻方具备绝对高中锋破密集战术或防守方禁区解围密度崩溃时除外 |
| 淘汰赛排位战与实力代差优先权(严禁凭留力战意抹平实力断崖) | 严禁以‘提前出线必打默契平/必然留力’等虚假叙事推导平局或受让！当实力代差达两档以上(基础Δλ≥1.50)时，板凳深度依然降维打击，战意调整严禁超过15% | 盲信留力剧本导致硬实力被主观抹杀、让球惨败被横扫(如09-23日本替补3:0泰国)；代差面前战意影响居次席 | 两队积分打平即可联手做掉第三方且淘汰赛半区无强弱差异时除外 |

## 塑形闭环

**触发情境 → 执行检查 → 记录判断 → 对照反馈 → 修正习惯。**
检查是否真的执行、是否减少信息遗漏与概率误差；不以写了多少规则、连了多少图谱边衡量学习。
优先养成三个动作：结论前找一个反例；改规则前找独立样本；复用经验前检查情境是否仍成立。
当数据充足且判断流程已稳定，可减少重复操作；当阵容、联赛、盘口或数据来源变化，重新检验适用性。

## 经验记录的最小格式

- 适用情境与触发信号：说明对什么问题有用，保留连续数值及样本信息。
- 检查动作与理由：下一次具体查什么、怎样可能改善决策；机制尚未证实时标为假设。
- 支持证据与反例：引用赛前封存及后续样本，成功失败都保留；缺少证据就写未知。
- 暂定调整、比较办法与后续反馈：允许不调整，区分拟议、试验中、已验证和已撤回。
- 失效条件：在哪些联赛、时间、市场或数据条件下不能照搬。

## 历史经验如何保留

旧七类盘口原型中的有用问题已转成上述检查习惯；“庄家必赚”“关闭had必然内幕”、固定得分和赛果否决不再作为公理。
旧战报原文仍在[档案目录](README.md)，用于检查当时推理；其中单场机构动机叙述、旧阈值与胜率宣称属于待核查材料。
[规则审计](README.md#rule-audit)保留变更依据与边界，避免遗忘错误来源，也避免把错误永久当成事实。

## 八篇复盘学术论文的闭环行动法则（彻底杜绝死板一刀切）

复盘不是为单场输赢找借口，更不是为每一次失手加一条死板禁令。本知识库八篇核心论文构成了不可动摇的科学复盘闭环：

1. **[Aiyer 等 (2023) 结果偏见与决策评价](../温故而知新学习资料/2023_Aiyer_结果偏见与决策评价.md)**：**过程与结果解耦**。赛后必须先遮住比分审核赛前推演逻辑与期望值，严禁因单场未平就否定科学策略，绝不允许单场成败推翻规则。
2. **[Hewamalage 等 (2023) 预测评估陷阱与最佳实践](../温故而知新学习资料/2023_Hewamalage_预测评估陷阱与最佳实践.md)**：**防事后偷看与过度切分**。严禁将每天轮换的临时场次代号当成经验分类，严禁事后对数据过度切分寻找虚假规律。
3. **[Wheatcroft (2019) 足球概率预测评分](../温故而知新学习资料/2019_Wheatcroft_足球概率预测评分.md)**：**完整概率质量评估**。使用 Brier Score 与 Ignorance Score 评估三项概率分布质量，绝不做简单粗暴的二元对错复盘。
4. **[Wilkens (2026) 德甲预测与滚动验证](../温故而知新学习资料/2026_Wilkens_德甲预测与滚动验证.md)**：**极简主义（KISS）与样本外检验**。简单模型往往优于过度复杂的规则堆砌；规则优化必须在滚动未知样本中检验，严禁叠床架屋堆砌例外。
5. **[Dimitriadis 等 (2021) 稳定可靠性图 (CORP)](../温故而知新学习资料/2021_Dimitriadis_稳定可靠性图_CORP.md)**：**大样本概率校准**。30% 的平局概率意味着 70% 的分胜负是正常物理分布；只有累积大样本偏离校准曲线才触发参数更新。
6. **[Giacomini & White (2006) 条件预测能力检验 (CPA)](../温故而知新学习资料/2006_Giacomini_条件预测能力检验.md)**：**假设预先冻结**。任何策略修正必须在事先冻结假设与检验窗口后进行统计检验，禁止赛后随兴解释。
7. **[Choe & Ramdas (2023) 序贯预测者比较](../温故而知新学习资料/2023_Choe_序贯预测者比较_arXiv_v6.md)**：**置信序列长期跟踪**。以时间序列动态跟踪模型累计表现，克服单日情绪波动，杜绝反复查看结果后的选择性偏差。
8. **[Macrì 等 (2025) 足球贝叶斯加权动态模型](../温故而知新学习资料/2025_Macri_足球贝叶斯加权动态模型_arXiv.md)**：**平滑衰减自适应**。球队攻防能力呈动态漂移，采用时间衰减平滑更新参数，绝不因单场突发赛果剧烈重置系统认知。
