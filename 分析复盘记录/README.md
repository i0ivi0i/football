## 三、 程序与 AI 脚本直读代码指南（Python 极简模式）

本解析逻辑由项目内置的 [对账机](../脚本/对账机.py) 原生驱动。Python 程序读取本目录下任意文档，**只需 3 行原生代码，0 第三方依赖**：

```python
import os, re, json

def load_record(file_path: str) -> dict:
    """直接读取任意预测或复盘 MD 文档顶部的结构化 JSON 卡片"""
    with open(file_path, "r", encoding="utf-8") as f:
        match = re.search(r"```json\s*(\{.*?\})\s*```", f.read(), re.DOTALL)
        return json.loads(match.group(1)) if match else {}

# 示例：获取历史记录
data = load_record("分析复盘记录/2026-09-12_预测.md")
print("头号猎物:", data["头号核心猎物"]["对阵"], "平赔:", data["头号核心猎物"]["平赔"])
```

## 四、 平局决策核心执行规则（人类与 AI 必背）

### 1. 决策分层门槛红线
* **$\ge 80$ 分**：【第一黄金猎物】（单挑平局，并重点狙击 1:1 或 0:0 波胆比分）；
* **70 ~ 79 分**：【双平对冲防守包】（必须平局搭配让球平，防范一球小胜）；
* **$< 70$ 分**：坚决剔除，绝不主观强行买平！

### 2. 四大安全断路器（微调铁律 · 杜绝翻车与漏网）
1. 🚫 **客队反扑能力一票否决**：客队落后即崩、近 10 场落后反扑扳平率 $<10\%$ 者直接剔除，防主队 1:0 死守到底；
2. 🛡️ **豪门替补爆点强制双平**：强队替补席有亿元神锋或国脚前锋者，一律倒扣 15 分，降级为“平局 + 让球平”双平对冲，防 85 分钟后球星个人绝杀；
3. 🪤 **豪门高平阻盘捕手**：主胜热门极低（$<1.70$）而平赔高挂 $3.60 \sim 3.90$，只要客队是联赛知名低位大巴，立即激活“冷平狙击”，收割主胜韭菜；
4. 🧱 **均势打铁低转化捕手**：双方胜负赔率咬死（水差 $\le 0.25$）且射门转化率 $<8\%$ 时，直接列为“0:0 / 1:1 闷平候选”！
5. 🚨 **庄家明牌开卷考绝不跳过**：体彩官方故意关闭普通胜平负仅开让球盘（had 为空）的场次，是机构切断极低水主胜、将散户赶入让胜的最高级内幕风控信号！终局以逼平（1:1）或小负通杀让胜散户，严禁视为无比赛跳过，必须全面执行双向狙击（Polymarket 8~12倍冷平 + 体彩双平闭环对冲）！

### 3. 全量数据榨干与 Graphify 超级深度推演协议
1. 📊 **football-data 海量数据倾尽协议**：任何预测与复盘必须强制调用 `football-data` 与微观适配器，榨干双方全量 H2H 历史交锋数据（总场次、胜平负、射正、角球比）、ClubElo 动态战力、Understat 单脚空间 xG 坐标与进球场景、核心球员推进链（`xg_chain`/`xg_buildup`）、门将扑救率、战术粗暴犯规数与休赛体能负荷，未核验微观数据严禁出票！
2. 🧠 **Graphify 超级深度模式（--mode deep）铁律**：赛前推演必须强制前置执行 `graphify query` 深度检索历史操盘手法与相似结构；赛后盲区审计必须执行 `graphify reflect` 与 `save-result` 固化断路器；全库 Markdown 严禁产生孤岛节点，连通分量恒为 1！
3. 🔗 **结论输出必带 Polymarket 直达链接铁律**：每一个得出的核心猎物结论后面，必须 100% 强制在正文直接附带真实可点击的 Polymarket 直达链接（`https://polymarket.com/zh/sports/{league}/{slug}`），严禁仅藏在代码块或遗漏，确保主人一键点击直达下注！

## 五、 三位一体实时协同与自动进化机制（AGENTS.md + README.md + graphify）

为了保证所有推演、复盘、总准确率与总结 100% 具备**自驱动实时性与知识沉淀闭环**，必须严格执行三位一体工作流：

```
[每日赛事完成]
       │
       ▼
1. 生成 YYYY-MM-DD_复盘.md (文首内嵌 JSON 卡片，严格执行赛前盲区审计)
       │
       ▼
2. 自动触发 脚本/对账机.py (0.2秒物理重算，毫秒级无缝刷新 总准确率.md 与 总复盘总结.md)
       │
       ▼
3. 自动触发 graphify update . (深度知识图谱更新，将实战赛果与断路器沉淀入知识拓扑)
       │
       ▼
4. AGENTS.md 宪法守卫 (下一任智能体唤醒时，首要读取最新指标与红线，绝不发生记忆漂移)
```

* **AGENTS.md（最高宪法）**：锁定智能体行为铁律、8层推演模型与一票否决红线；
* **README.md（执行手册）**：规范数据契约、JSON 卡片 Schema 与对账接口；
* **graphify（记忆大脑）**：将分散的每日战报与学术论文深度织网，实现战术与赔率模式的自适应学习！
