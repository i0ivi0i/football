# 足球量化推演专业术语表 (Glossary)

本文档持续记录本项目在 AI 精准推演足球比赛“胜负平”中确立的核心术语与定义。

---

## 1. 核心模型与算法 (Models & Algorithms)

| 术语 | 英文 / 原文 | 定义与项目内涵 |
| :--- | :--- | :--- |
| **期望值 (+EV)** | Expected Value | 数学期望收益率：$EV = (P_{真实} \times Odds) - 1$。当 $EV > 0$ 时，代表长期重复下注具有正向数学期望。本项目以此作为全盘决选的核心排序指标（参见 ADR 0002）。 |
| **Shin 算法** | Shin (1993) / Strumbelj (2014) | 逆向破译庄家抽水的经典精算算法。将市场赔率分解为知情内幕交易者比例 $z$ 与无偏客观真实概率 $p$，优于朴素的倒数比例归一化。 |
| **泊松联合分布** | Dixon & Coles (1997) | 以双方各自进球期望值 $(\lambda_1, \lambda_2)$ 为参数，并对低比分 $(0:0, 1:0, 0:1, 1:1)$ 施加相关性参数 $\rho$ 修正的双变量泊松得分矩阵模型。 |
| **尖端做市商** | Sharp Bookmakers | 以 Pinnacle (平博)、Betfair (必发交易所) 为代表的低抽水、高限额机构。其最终盘口价格被学术界与量化界公认为市场真实概率的最有效无偏估计。 |
| **零售庄家** | Retail Bookmakers | 以 Bet365、中国竞彩 (Sporttery) 为代表面向大众散户的机构。其赔率受公众情绪与投注倾斜影响严重，常产生可被捕捉的滞后定价偏差。 |

## 2. 交易与推演策略 (Trading & Forecasting Strategy)

| 术语 | 英文 / 原文 | 定义与项目内涵 |
| :--- | :--- | :--- |
| **最佳价值模式** | Best Value Mode | 打破胜、平、负的人为割裂分类，全盘 100% 逐场过筛后，每日仅严格推选综合胜率与 +EV 最高的 1~2 场“头号价值标的”（无论是胜、是平还是负）（参见 ADR 0001）。 |
| **双引擎校准** | Hybrid Engine Architecture | 第一引擎采用平博/必发经 Shin 算法去水所得的客观基准概率；第二引擎采用独立 xG 攻防与首发伤停微观变量进行扰动校准，输出最终综合概率（参见 ADR 0003）。 |
| **长赔率偏见** | Favourite-Longshot Bias (FLB) | 行为经济学定理（Forrest 2008）：散户偏爱高赔冷门与强队大热，庄家在冷门和平局上施加惩罚性高抽水。量化系统须识别并剔除虚假高赔彩票。 |
| **零级风控关盘** | Closed HAD Market | 中国体彩官方因两队硬实力极度悬殊而关闭普通胜平负（仅开让球盘）的明牌现象。系统强制 100% 前置推演，严防将豪门碾压误判为爆冷平局。 |
| **动态阶梯定注** | Tiered EV Staking | 资金管理标尺：+EV < 3% 为 0 单位空仓；3%~6% 为 1 单位（底仓）；6%~10% 为 2 单位（主力）；≥10% 顶格 3 单位封顶防爆仓（参见 ADR 0007）。 |
| **异动自适应重估** | Adaptive Odds Recalibration | 当平博/做市商变盘位移 $|\Delta Odds| \ge 0.15$ 或水位波动 $\ge 8\%$ 时，自动重算最新 +EV 并实时调整阶梯注码建议（参见 ADR 0008）。 |
| **低赔安全边际** | Low-Odds Safety Margin | 针对做市商赔率 $< 1.50$ 的超低赔稳胆选项，为击碎庄家极端抽水与散户胜率幻觉，强制要求真实概率超出市场隐含概率 $\ge 5\%$，且 $EV > 0$，否则一律按负期望陷阱一票否决（参见 ADR 0002）。 |
| **串关通吃收割** | Accumulator Harvesting | 庄家利用散户将低赔作为必胜稳胆连环串关的习惯，在豪门暗藏体能战术危机时故意开出低赔诱聚全盘资金，通过冷平/冷负一举爆杀全盘串关彩票的最大化暴利机制（参见 ADR 0010）。 |
| **庄家对赌头寸** | Position-Taking Bookmaker | 经济学诺奖级实证（Levitt 2004）：庄家并非中立佣金撮合商，而是主动利用信息差与散户认知偏差同公众反向对赌、通过吃下大热负期望头寸赚取垄断暴利（参见 ADR 0010）。 |
| **初盘锚点** | Opening Line Anchor | 尖端做市商最早放出的基准盘口与水准，作为衡量全天市场情绪偏离度与机构诱盘位移的恒定基准坐标（参见 ADR 0012）。 |
| **赔率时序流水** | Odds Movement Time-Series | 通过商业赔率 API 提取的连续时间戳变盘记录，完整呈现升降水历史与流动性聚散，彻底解决单点静态盲区（参见 ADR 0012）。 |
| **多元做市商矩阵** | Multi-Bookmaker Matrix | 联合平博(Pinnacle)+Bet365+必发(Betfair)+皇冠(SBOBET)+体彩(Sporttery)形成主备交叉对账网络，粉碎单一做市商信息茧房与孤立诱盘假象（参见 ADR 0012）。 |
| **逆向变盘 (RLM)** | Reverse Line Movement | 散户资金极度涌入某方，做市商反而反向升水/降盘，表明机构宁抗散户敞口也要跟随极少数职业聪明钱对赌，为大热必死最强信号（参见 ADR 0013）。 |
| **欧亚背离度** | Euro-Asian Divergence | 欧洲标盘精算概率与亚洲让球盘深度之间的非对称落差，用于识别机构“浅盘诱上”或“深盘赶下”的资金诱导口袋（参见 ADR 0013）。 |
| **做市商离散度 (凯利方差)** | Kelly Variance / Dispersion | 主流做市商（体彩、平博、Bet365等真实可测机构）报价的离散度 $\sigma^2$。当某项离散度极低且伴随正向价格错位时，表征市场对该项达成强共识；严禁夸大为虚假50家高频方差，缺失强制标 [N/A]（参见 ADR 0013/0014）。 |
| **空仓第一铁律** | Pass / Empty Position Rule | 当全天开售场次中没有任何一场达到 +EV 门槛或存在致命数据缺失时，坚决执行一股不买、全天观望，保全资金安全为最高原则。 |

## 3. 交互呈现与复盘闭环 (Interaction & Review)

| 术语 | 英文 / 原文 | 定义与项目内涵 |
| :--- | :--- | :--- |
| **极简秒看卡片流** | Minimalist Fast-Decision Card | 赛前聊天窗口默认且仅输出工整紧凑的决策卡片（对阵、推荐方向、赔率、+EV、阶梯仓位、Polymarket 链接），剥离冗长推演叙述，追求极致决策效率（参见 ADR 0005）。 |
| **Polymarket 刚性链接** | Verified Polymarket Linking | 每次推演结论后强制附带 100% 真实核验的专属直达链接及其实时现价；若官方未开盘则如实标注，绝不造假（参见 ADR 0009）。 |
| **Aiyer 学术解耦复盘** | Outcome Bias Decoupling (Aiyer 2023) | 赛后遮盖赛果重新复审赛前逻辑，将赛果与决策质量完全解耦，详查数据误差与推理缺口，产出千字深度复盘并自动吸收进 Graphify 知识图谱（参见 ADR 0006）。 |
| **双技能做实基建** | Dual-Skill Grounding | 深度结合 football-match-analysis（基本面泊松+Elo+纯数学EV）与 football-betting-analysis（8层分析+真实伤停+Shin去水），只计算可验指标，凡未接入项强制打上 N/A 水印，彻底斩断空中楼阁与模型幻觉（参见 ADR 0014）。 |
| **伤停泊松衰减** | Injury-Poisson Calibration | 将物理查明的真实伤停（门将/中卫/射手）量化映射为攻防参数衰减（$\Delta\alpha, \Delta\beta$），重新生成泊松比分矩阵与无偏胜平负概率，捕捉零售庄家定价迟钝产生的超额 +EV（参见 ADR 0015）。 |
| **战术球商穿透** | Tactical Wisdom Penetration | 超越静态数字，深入剖析打法相克、赛程体能耐受与时间轴拐点（如青年军60分钟雪崩）、避险动机与更衣室深层心理的四维全息穿透机制（参见 ADR 0003/0015）。 |
| **战术智慧一票否决** | Tactical Veto Authority | 当 AI 从战术克制或动机崩溃判定某方存在不可逆系统性崩盘时，即使静态数据模型 EV 为正，也坚决一票否决主推，防范做市商诱盘深坑（参见 ADR 0002）。 |
