# ADR 0005: 极简秒看卡片流交付架构 (Minimalist Fast-Decision Card Layout)

- **状态**: Accepted (已采纳)
- **决策日期**: 2026-09-22
- **决策人**: 主人与 Antigravity AI 对齐确认

---

## 背景与问题陈述 (Context)
用户明确反馈：“你回答我的时候应该工工整整搞个表格，你写成一堆，我都看不清楚了”。过多的背景铺垫、战术叙述、推演长文会严重稀释核心决策信息，增加阅读负担，违背金融交易与实盘博弈追求快速高效决策的第一性原理。

## 决策内容 (Decision)
1. **剥离所有冗余长文**：对话输出彻底舍弃大段的战术描述、过程复述与背景铺垫。
2. **极简表格卡片化呈现**：聊天窗口默认且仅输出工工整整的核心决策表格，列结构严格统一定型为标准 6 列不可缺少契约：
   `| 场次/时间 | 对阵双方 | 终审人话指令 | 真实赛果剧本 | 庄家诱盘破译 | Polymarket 真实链接 |`
   - **直给终审操作指令**：严禁在推荐栏仅写抽象的“一票否决”，必须明确直给行动建议：【胜】、【平】、【负】或【🛑 观望空仓】；
   - **剧本内嵌高密度球商胜负手**：‘真实赛果剧本’直击战术终局（比分），‘庄家诱盘破译’直击【战术相克死穴 + 动机体能胜负手 + 机构诱热陷阱】；
   - **Polymarket 刚性必带**：最后一列 100% 刚性必带实测存活链接或官方未开盘 ❌ 说明，严禁漏列；
   - **空仓执行标尺**：凡胜平负全项 EV ≤ 0 或触发战术致命陷阱的场次，推荐方向统一标为【🛑 观望空仓】，仓位标为【0u 绝不买】，并给出避坑说明；
3. **全流程静默于后台**：所有 8 层推演、四维战术穿透、微观伤停排查全部在 AI 内部自查完成，对话界面只呈现最终提纯后的高价值决策卡片。

## 影响与收益 (Consequences)
- **正面收益**：一目了然、秒看即决，信息密度极高，彻底满足主人对于工整表格与高效决策的诉求。
- **潜在代价**：若主人某天需要详查特定场次的推演过程细节，需主动发出“展开分析”指令。
