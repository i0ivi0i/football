# ADR 0012: 专业赔率 API 时序流与盘口波动追踪架构 (Professional Odds API Time-Series Integration)

- **状态**: Accepted (已采纳)
- **决策日期**: 2026-09-22
- **决策人**: 主人与 Antigravity AI 对齐确认

---

## 背景与问题陈述 (Context)
在既往推演中，系统仅在推演触发时单点获取即时赔率（静态单张照片），导致缺乏时序深度，无法直观掌握机构从开盘到临场的“诱盘、升降水、洗盘位移”。主人明确指示：“有了实时记录，你不就知道波动了吗？”

## 决策内容 (Decision)
1. **接入全球多元做市商 API 矩阵 (Multi-Bookmaker Matrix)**：
   - **第一主力 (Sharp Benchmark)**：The Odds API —— 深度捕获尖端做市商 Pinnacle (平博)、零售大庄 Bet365、交易所 Betfair 的无偏价格与原生 `/historical` 变水时序；
   - **第一备用 (Broad Coverage)**：API-Football (API-Sports) —— 覆盖全球 1000+ 联赛，备用提供多庄家 `/odds/history` 变水流水，保障冷门联赛不漏水；
   - **亚洲盘与深度撮合 (Asian Handicap & Exchange)**：BetsAPI / Betfair API —— 补齐 SBOBET (皇冠/沙巴) 亚洲让球盘资金流与必发真实成交量，破除单一机构诱盘假象；
   - **零自定义脚本维护**：纯粹利用平台标准化 HTTP/JSON 协议直取数据，严格杜绝任何私有代码文件。
2. **全维度微观盘口采集范围（不限于 1X2 独赢盘）**：
   - **A. 赛果衍生**：亚盘让球、净胜球、双进球(BTTS)、胜且零封、落后逆转；
   - **B. 时间维度**：半全场、首球时段、特定10分钟区间盘、补时精确时长、最高得分半场；
   - **C. 场面维度**：角球数(大小+竞速)、控球率、越位数、率先达到X角球；
   - **D. 碎片维度**：射门射正、犯规红黄牌、界外球、门球、VAR介入次数、门将扑救、抢断、被犯规；
   - **E. 个人维度**：核心球员进球、吃牌、单人传球数、替补进球、头球/任意球/远射破门、中柱。
   - **双引擎交叉**：外部从 Pinnacle(锚) + Bet365(广度) + 体彩(散户情绪) 实时采集微观盘口真实倍率；内部用泊松矩阵推算"隐含角球/犯规期望值"模拟无盘口维度，两套引擎互不替代。
2. **三态时间轴数据模型**：
   - **初盘锚点 (Opening Line)**：记录做市商最早开出的基准赔率与水准；
   - **异动流水 (Line Movement Stream)**：记录每次做市商变盘的时间戳、赔率变动值与水位差；
   - **临场终盘 (Closing Line)**：记录推演时刻的最新有效盘口。
3. **闭环联动 ADR-0008**：
   - 当检测到时序波动 $|\Delta Odds| \ge 0.15$ 或水差波动 $|\Delta Water| \ge 8\%$ 时，系统自动在推演中标识【机构洗盘异动】，并触发概率与 +EV 的即时重估。

## 影响与收益 (Consequences)
- **正面收益**：推演拥有完整的历史时序纵深，彻底看清机构洗盘与诱盘轨迹，大幅提高防收割与冷门捕捉的敏锐度。
- **潜在代价**：需确保商业 API 额度与查询频率的高效管控，推演优先聚合查询，避免高频无谓消耗。
