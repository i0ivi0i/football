# ADR 0014: 双引擎融合做实基建与防幻觉物理门禁 (Hybrid Dual-Skill Grounding & Anti-Hallucination Gate)

- **状态**: Accepted (已采纳)
- **决策日期**: 2026-09-22
- **决策人**: 主人与 Antigravity AI 对齐确认

---

## 背景与问题陈述 (Context)
系统自查与复核揭示：此前由于缺少商业级多源时序 API，推演中存在将离散快照夸大为“50家高频凯利方差”的局部概念幻觉。为践行求真底线与第一性原理，决议采纳 **B 方案（迎难而上·做实基建）**：深度结合 `football-match-analysis`（泊松回归/Elo/纯数学+EV/Kelly仓位）与 `football-betting-analysis`（8层分析/真实伤停/Shin去水/盘口异动），构建真实可验的双引擎闭环，彻底根除大模型空中楼阁与口嗨脑补。

## 决策内容 (Decision)
1. **数据引擎硬分工与互锁**：
   - **客观数据引擎 (football-data / sports-skills)**：主责 ESPN 全球赛程对账、联赛官方积分榜、Understat xG、FPL 伤停与 Transfermarkt 球员微观档案，作为全系统第一道物理事实底座；
   - **基本面引擎 (football-match-analysis)**：主责球队攻防参数（$\lambda_{home}, \lambda_{away}$）、Elo 实力差、泊松全比分分布矩阵、全盘纯数学 +EV 极值排序与 Kelly 动态阶梯注码；
   - **盘口行为引擎 (football-betting-analysis)**：主责 FlashScore 物理伤停大名单（missingPlayers）、Shin 算法反推市场内幕概率、初盘 vs 即盘真实离散位移（$|\Delta Odds|$, $|\Delta Water|$）。
2. **做市商矩阵求真收敛（坚决剔除虚假包装）**：
   - 严禁宣称“50家全量毫秒凯利方差”，收敛为【体彩官方在售 + Pinnacle + Bet365/主流机构】真实可采样的做市商矩阵；
   - 仅在获取真实初盘锚点与即盘快照时计算位移差分；无初盘历史时如实标注【单点即盘快照】，杜绝虚构时序流。
3. **防幻觉水印与一票降级门禁**：
   - **伤停物理硬门禁**：未调取到真实伤停数据时，强制打上 `[伤停: 缺失未测]` 水印并一票降级，严禁脑补全员健康；
   - **数据透明化底线**：凡未接入实时数据的指标，决策卡一律直显 `[N/A·未接入]`，绝不允许大模型脱口编造数值。
4. **数据源平替 Schema 字段级对齐门禁**：
   - 严禁跨品类混淆数据源（严禁将做市商赔率 API 混充为微观球员数据的平替）；
   - 任何数据源平替提议，必须前置对照底层返回字段（如 missing_players、lineups、xg、ratings），未经字段级 1:1 核验严禁宣称平替。

## 影响与收益 (Consequences)
- **正面收益**：彻底消除理论与落地之间的虚妄鸿沟，让每一场推演的概率、EV与决策建议都 100% 建立在物理可查证的硬核数据之上。
- **潜在代价**：缺少数据时不再有华丽修饰，部分场次会直白显示 N/A 并触发空仓，但保全了系统长期生存的诚信与胜率生命线。
