# ADR 0008: 异动阈值自适应重估机制 (Adaptive Odds Movement Recalibration)

- **状态**: Accepted (已采纳)
- **决策日期**: 2026-09-22
- **决策人**: 主人与 Antigravity AI 对齐确认

---

## 背景与问题陈述 (Context)
足球比赛临场盘口受聪明资金（Sharp Money）进场与主力伤停突发影响，赔率往往在临开赛前数小时内发生剧烈漂移。若系统死守早盘静态数据，早盘发现的 +EV 空间可能因临场降水而被彻底抹平甚至变为负期望；反之，某些早盘平庸的场次可能因临场升水出现暴利错价。

## 决策内容 (Decision)
1. **设立灵敏度异动硬门槛**：
   - 做市商（Pinnacle / Betfair）独赢盘赔率绝对位移 $|\Delta Odds| \ge 0.15$；
   - 或市场隐含概率/水位波动 $|\Delta Water| \ge 8.0\%$；
   - **微观盘口硬阈值**：角球/犯规/射正/黄牌/BTTS/补时等任一非独赢盘品类倍率位移 $\ge 10\%$，同样强制触发重算，一刀切无例外。
2. **异动触发自动重估流水线**：
   - 一旦候选场次突破上述异动阈值，系统自动调用 Shin 算法与微观模型重新测算当前最新 $+EV$；
   - 根据最新 $+EV$ 实时调整阶梯注码挡位（0/1/2/3 档）；
3. **输出极简异动修正卡**：
   - 若 $+EV$ 缩水至 $<3.0\%$，立即发出“**错价消失·降为0注空仓**”警报；
   - 若升水扩大产生更高 $+EV$，触发“**价值升级·追加注码**”建议。

## 影响与收益 (Consequences)
- **正面收益**：推演结论高度贴合实盘动态生命周期，彻底告别“刻舟求剑”，对大资金暗涌具有极高防御力和捕获力。
