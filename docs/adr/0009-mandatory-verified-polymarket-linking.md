# ADR 0009: 真实 Polymarket 盘口链接刚性交付机制 (Mandatory Verified Polymarket Linking)

- **状态**: Accepted (已采纳)
- **决策日期**: 2026-09-22
- **决策人**: 主人与 Antigravity AI 对齐确认

---

## 背景与问题陈述 (Context)
主人明确要求：“你每次给出足球场次分析推演答案的时候，后面要跟上正确的对应场次的 polymarket 链接”。作为面向实盘决策与去中心化预测市场交易的量化系统，仅给出抽象方向而不附带可执行的真实市场交易入口，会极大损耗交易执行效率；同时，若链接失效或胡乱拼凑编造，更会造成严重的误导与资金风险。

## 决策内容 (Decision)
1. **推演交付刚性标配**：在极简卡片流或任何场次分析推演结论中，**强制标配该场次专属的 Polymarket 真实直达链接**。
2. **物理核查与免死防线**：
   - **已开盘场次**：附带经核验的完整官方 URL（如 `https://polymarket.com/zh/sports/sea/sea-udi-cag-2026-09-19`），并同时注明 Polymarket 盘面实时现价（例如 `平局 29.5¢，折合 3.39倍`）；
   - **未开盘场次**：若小联赛、次级杯赛 Polymarket 官方未上线该单场流动性池，必须诚实明标“**Polymarket 官方未开单场盘 ❌（仅限体彩票务执行）**”，严禁任何形式的盲目编造死链接或伪造页面！
3. **闭环防篡改**：推演生成的 Polymarket 链接必须与分析的联赛、对阵双方及开球日期 100% 对应一致。

## 影响与收益 (Consequences)
- **正面收益**：推演与交易 100% 无缝咬合，主人秒看分析后即可一键直达交易池，极致提升实盘操作体验与执行效率。
- **诚信保障**：严格遵守《AGENTS.md》不伪造链接底线，保障全系统数据链的绝对严谨。
