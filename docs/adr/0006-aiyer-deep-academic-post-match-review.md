# ADR 0006: 严格学术解耦深度长篇复盘架构 (Aiyer 2023 Academic Review Framework)

- **状态**: Accepted (已采纳)
- **决策日期**: 2026-09-22
- **决策人**: 主人与 Antigravity AI 对齐确认

---

## 背景与问题陈述 (Context)
在赛后对账与复盘环节，散户和业余预测者最容易犯下“以赛果倒推因果”的结果偏见（Outcome Bias）。例如：推胜打平就以为庄家控盘；推错就胡乱修改规则。赛后复盘必须与赛前决策质量严格解耦，成为真正的知识图谱进化引擎。

## 决策内容 (Decision)
1. **严格遵循 Aiyer (2023) 理论**：遮盖赛果重新复审赛前可知依据，将赛果完全解耦为四种情况：
   - 好决策 + 好结果（技能发挥）
   - 好决策 + 坏结果（可接受的概率方差波动）
   - 坏决策 + 好结果（侥幸踩中，须严厉追责逻辑漏洞）
   - 坏决策 + 坏结果（彻底惩处数据/推理盲区）
2. **长篇千字深度归因报告**：生成独立的《YYYY-MM-DD_复盘.md》，必须覆盖：
   - 赛前已知事实与信息盲区审计
   - 微观阵容数据核验（首发与伤停执行度）
   - 概率模型对数损失 (Log Loss) 与 Brier 评分
   - 根因归因与规则防僵化审查（不盲目新增无效禁令）
3. **Graphify 知识图谱物理闭环**：复盘生成的教训与因果链必须作为新节点/新边自动吸收进 `graphify-out/graph.json`，在后续赛前推演中触发物理排雷阻断。

## 影响与收益 (Consequences)
- **正面收益**：形成真正的科学复利进化，每一次错误都成为不可磨灭的知识图谱免疫抗体。
- **与赛前模式的协同**：与 ADR 0005 形成完美对比——“**赛前极简秒看，赛后深剖千字**”！
