# ADR 0002: 纯数学 +EV 期望值导向决选机制 (Pure Mathematical +EV Orientation)

- **状态**: Accepted (已采纳)
- **决策日期**: 2026-09-22
- **决策人**: 主人与 Antigravity AI 对齐确认

---

## 背景与问题陈述 (Context)
在筛选全盘候选时，存在两种设计路线：
- 路线 A：设定固定的主观硬性胜率门槛（如主胜必须 $\ge 60\%$、平局必须 $\ge 28\%$、赔率必须在 1.60~2.80 之间）；
- 路线 B：以纯数学期望值 $EV = (P_{真实} \times Odds) - 1$ 作为统一标尺，不论绝对赔率高低，完全以市场错误定价（Mispricing）的幅度大小来排序决选。

## 决策内容 (Decision)
1. **采用纯数学 +EV 优先原则**：放弃僵化的主观胜率硬切点，完全以 $EV$ 幅度排序。核心捕获的是“市场实际赔率相较于真实客观概率被严重低估”的超额正期望机会。凡 $EV \le 0$（哪怕 1.15 的所谓稳胆）一律一票否决。
2. **战术智慧一票否决权（AI 球商熔断）**：数学 EV 仅作为防亏底座；若 AI 深度球商从战术阵型相克、体能断崖拐点或淘汰赛避险动机判定某方存在致命崩盘陷阱，即使静态数据模型 EV 为正，也坚决一票抹杀；当 AI 捕捉到底层战术相克的致命杀招时，允许破格给予微仓价值推荐。
3. **超低赔安全边际硬卡（破除稳胆执念）**：针对赔率 $< 1.50$ 的超低赔选项，庄家抽水极重且公众情绪过度溢价（FLB偏差），强制执行双重门槛：除 $EV > 0$ 外，真实模型概率必须领先市场隐含概率 $\ge 5\%$ 的安全边际，否则坚决一律空仓过滤。
4. **资金下注与置信度解耦**：期望值负责“选不选”，置信度与方差负责“仓位控制（Half-Kelly / 阶梯注码）”。

## 影响与收益 (Consequences)
- **正面收益**：完全遵循长期大数定律与金融做市商博弈本质，长期期望收益率最大化。
- **潜在代价**：当高赔选项（如平局 3.20）具备极高 +EV（如 +15%）时入选，单场方差波动较大，需严格配合仓位管理，杜绝重注。
