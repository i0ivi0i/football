# ADR 0003: 尖端做市商去水与独立微观修正双引擎架构 (Hybrid Probability Engine)

- **状态**: Accepted (已采纳)
- **决策日期**: 2026-09-22
- **决策人**: 主人与 Antigravity AI 对齐确认

---

## 背景与问题陈述 (Context)
在计算 $+EV = (P_{真实} \times Odds) - 1$ 时，核心变量是客观真实概率 $P_{真实}$。如何计算 $P_{真实}$ 决定了整个系统的立足基石：
- 若纯靠统计模型（Elo/泊松）：容易忽视球队临场资金暗涌与未公开核心伤停；
- 若纯靠单一赔率归一化：循环引用、陷入庄家抽水迷宫；
- 若纯靠散户盘口：会被大众热门偏见严重带偏。

## 决策内容 (Decision)
1. **第一引擎（基准锚点）**：以全球公认定价最有效的聪明做市商（Pinnacle 平博、Betfair 必发交易所）的终盘/临场数据为基准，采用 **Shin (1993) / Strumbelj (2014) 算法**剥离知情内幕参数 $z$，反推无偏市场隐含概率。
2. **第二引擎（AI 战术球商与微观修正）**：深度引入独立的 **Dixon-Coles 进球期望 $(\lambda_1, \lambda_2)$ 攻防模型**与 **AI 四维战术博弈穿透**（阵型相克、体能断崖拐点、避险战意动机、中轴代偿能力），将鲜活现场洞察动态映射为进球期望扰动，与第一引擎形成定性与定量的水乳交融。
3. **套利与价值发现**：将综合概率 $P_{真实}$ 与中国竞彩（或目标零售盘口）的实时报价对比，直接扫描出因机构迟滞、信息差或散户偏见形成的 $+EV$ 错价点。

## 影响与收益 (Consequences)
- **正面收益**：兼备顶级做市商的宏观资金无偏性与球队微观阵容的战术敏感性，彻底告别单盲区推演。
