# ADR 0001: 全盘单一最佳价值推演模式 (Best Value Mode)

- **状态**: Accepted (已采纳)
- **决策日期**: 2026-09-22
- **决策人**: 主人与 Antigravity AI 对齐确认

---

## 背景与问题陈述 (Context)
此前系统存在“平局偏食症”，将平局孤立作为主要研究对象，导致当某些比赛日盘面缺乏均势平局温床时，系统容易为满足“平局推荐”而降低准入门槛，强推勉强标的（引发多起失手事件）。同时，主胜稳胆与冷门客胜等具备极高确定性的胜负标的被系统性忽视。

## 决策内容 (Decision)
1. **打破分类界限**：系统推演不再将“胜、平、负”人为割裂为独立模块，而是对当日开售全量场次的胜平负三向空间进行 100% 逐场全覆盖扫描。
2. **AI 球商与全盘最佳价值咬合**：融入 AI 战术球商与全息博弈穿透（打法相克、体能断崖拐点、淘汰赛半区避险战意），结合数学 +EV 极值，全盘仅优选综合确定性最高的 1~2 场“今日头号最佳价值标的”（无论是胜、是平还是负），坚决告别脱离比赛现场的机械套公式。
3. **允许完全空仓**：若全盘无任何一场满足高价值标准或战术存在巨大不可控黑天鹅，系统坚决宣告全盘空仓，一股不推。

## 影响与收益 (Consequences)
- **正面收益**：彻底消除平局偏食导致的强行凑单，系统选标自由度扩展至全盘，命中率与资金安全性大幅提升。
- **潜在代价**：用户若在特定时段只想寻找单一平局场次，需明确下发专项指令，系统默认交付全盘综合价值最高解。
