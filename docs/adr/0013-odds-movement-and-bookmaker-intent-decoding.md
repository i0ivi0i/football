# ADR 0013: 盘口时序异动与庄家意图反向破译引擎 (Odds Movement & Bookmaker Intent Reverse Decoding Engine)

- **状态**: Accepted (已采纳)
- **决策日期**: 2026-09-22
- **决策人**: 主人与 Antigravity AI 对齐确认

---

## 背景与问题陈述 (Context)
拥有时序赔率数据后，核心目标是从被动看数字升级为**主动破译大庄家的操盘意图（诱盘、杀热、洗盘、串关收割）**。国际金融计量学（Kaunitz 2017, Tomczak 2024, Winkelmann 2025）与顶级职业基金（Starlizard）证实，利用盘口动态变化反向破译机构意图是战胜做市商的关键武器。

## 决策内容 (Decision)
1. **构建三维意图破译量化流水线**：
   - **第一维：逆向盘口异动 (Reverse Line Movement, RLM)**：当大众散户资金极端涌入热门（如 75%+ 票数），尖端做市商（Pinnacle）却反向升赔退盘时，判定为【机构反向站队聪明钱，大热必死】，一票抹杀热门主推；
   - **第二维：欧亚背离检测 (Euro-Asian Divergence)**：比对欧洲胜平负概率与亚洲让球盘深度。若欧赔支持深盘但亚盘给浅盘低水，判定为【浅盘诱热陷阱】，反向下盘；
   - **第三维：真实做市商离散度 ($\sigma_{Kelly}^2$)**：监控体彩、Pinnacle、Bet365 主流真实做市商报价的离散度。当胜平负某项离散度极小且伴随正向价格错位时，判定为市场共识价值项；缺失时强制标记 [N/A·缺失未测]，严禁虚构50家高频方差。
   - **第四维：微观盘口背离穿透 (Micro-Odds Divergence Penetration)**：将角球/犯规/射正/黄牌/BTTS/补时等微观盘口倍率波动方向与独赢盘方向交叉比对。当独赢盘降水看好热门，但犯规/黄牌盘口同步走低（预示泥潭绞肉战）或角球盘口萎缩（预示围攻乏力），判定为【微观背离·独赢盘诱盘信号】，直接联动 ADR-0008 强制重算。
2. **零代码纯算法嵌入**：
   - 所有破译指标基于标准 API 时序数据流直接进行纯数学差分与方差计算，不依赖任何私有本地脚本；
3. **决策卡直给意图标签**：
   - 结果在极简决策卡中直观标注机构意图信号（如【🚨 RLM 狙击大热】、【💡 主流共识收敛】、【⚠️ 欧亚浅盘诱上】），为最终【胜/平/负/观望空仓】提供硬核逻辑支撑。

## 影响与收益 (Consequences)
- **正面收益**：推演从静态数字预测跃升为博弈级真实破译，精准避开做市商诱盘深坑，捕捉超额 +EV。
- **潜在代价**：需多源时序数据支撑，数据缺失时降级为基准泊松推演。
