## 治理铁律

- ADR 总数永久冻结于 **16 项**，严禁新建。
- 新方法论必须融入最近邻既有 ADR，必要时扩展该 ADR 标题与范围。
- 杜绝孤岛式碎片化；每次修改后执行 `graphify update .` 同步图谱。
